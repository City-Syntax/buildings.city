Local-first UBEM Platform V2.0

Build Your City's
Interactive Energy Map

Turn one GeoJSON building dataset into a local-first Urban Building Energy Modeling application. Visualize archetypes, energy, and carbon metrics, predict missing labels, run EnergyPlus workflows, and sync reviewed results back into your active data.

Download the Latest Package Explore Live Demo

3-Step Deployment

  • 1
    Configure Your City: Update user-data/config.json and point to your GeoJSON dataset.
  • 2
    Explore & Review: Visualize archetypes, energy, and carbon on the map, then refine missing labels.
  • 3
    Launch: Run npm run dev for the dashboard. When needed, start the optional APIs in separate terminals for archetype prediction and EnergyPlus simulation.
Optional APIs
# Run each optional API in its own terminal
$ npm run ml:start
> ML API: http://localhost:8000
> Predict missing archetypes from known labels.
$ npm run simulation:start
> Simulation API: http://127.0.0.1:8010
> Generate IDFs, run EnergyPlus, and return results.
> Review outputs, then sync approved data back into GeoJSON.
Interactive Workflow

From city map to prediction and simulation

01 / Live Map

Read the city through building archetypes

Start with a colored 3D map, filter archetype categories, and inspect the dataset before committing any model or simulation output.

02 / ML API

Predict unknown labels without leaving the app

The local random-forest service trains on known buildings, reports model quality, and lets you review predictions before syncing them back.

03 / Simulation API

Select buildings and run EnergyPlus workflows

Define targets and context radius, generate simulation inputs, then bring reviewed outputs back into the same GeoJSON-centered workflow.

Dynamic Visualization

Mapbox-powered 3D extrusion with real-time filtering for GFA, Height, and Archetype categories.

ML Classification

Built-in random-forest pipeline for inferring missing archetypes from your own city dataset.

Simulation Workflows

Optional local EnergyPlus workflows for preparing templates, generating IDFs, and reviewing simulation outputs.

Data Synchronization

Write reviewed predictions, edits, and simulation results back to your active GeoJSON through a secure local API. Keep your dataset synchronized across all applications.
